## 正文

通关之后想再打一遍喜欢的首领，却发现打过的就再也见不到了？做了一个 MOD 来解决这件事：**残影试炼**（BOSS RUSH）。

随时随地，在任意铃铛处再战昔日强敌。入口就在铃铛菜单里，「穿行」下面多了一项「残影试炼」。用的全是游戏自己的按钮、字体、转场和首领血条，玩起来就像游戏自带的模式，手柄可以全程操作。

**两种玩法**
- **单挑**：74 位首领任选一位，再战一场；多阶段的首领只占一行，各阶段连着打完；玉妖和铁鬼一起登场。按首领出场的顺序排列，翻页就能找到。
- **连战**：连续挑战一组首领。千影归来是全部首领，按地图分成九段，每段单独一局；另有 11 个主题组，比如鬼差夜巡、百戏偶人、灭法之法、金铁玉面、江湖险恶、妖异志怪、铁马残阳。每组越打越强，最强的压轴，在为它选定的场地开打。两战之间回一点血，倒下即失败。

**打起来是什么样**
- 场地可以在残影试炼的「设置」里选「战斗 · 场地」：自动、就近（当前地图上最近的场地，不用加载）或随机（去过的名胜里随机，不重复前两局）。自动是默认：你正站在某个场地，就原地开打；否则去为该首领或该组选定的场地（敲响其铃铛后），或你去过的名胜，比如斧老大斩落处、丝线缠绕的巨树、初见湖畔、横刀平台、祠堂广场。每个场地都量过，离铃铛有一段距离，站位和首领出现点四周都是开阔平地。
- 首领强度跟着你的进度走，用的是游戏自己的怪物等级曲线：后期回头打前期首领，照样有挑战；多周目时随周目继续变强，和游戏原生敌人一致；难度跟随游戏设置；嫌不够难，可在残影试炼的「设置」里选「敌方 · 强度 · 二重～五重」，首领生命和攻击更高。
- 多阶段的首领一口气打完：比如金面具黑衣人之后是魔渊，七星剑阵：大师兄之后是绝望剑意和红衣女剑客一起登场，阶段之间不回血。
- 首领有出场：加载完后先在它要出现的位置浮现征兆，首领在其中现身，原地停 1.5 秒再行动。
- 想走随时能走：游戏菜单 → 系统 → 退出游戏，选「残影试炼：退出战斗」。
- 打完弹出结算画面，显示用时、最佳纪录、击败数和难度；按确认键回到出发的铃铛旁，血量和药瓶都恢复到出发前。

**没有副作用**
挑战里击杀首领不掉落、不给意识尘埃，不影响图鉴、任务和剧情。MOD 从不写入存档，最佳纪录和设置存在 `游戏目录\ProjectPBZ\Saved` 下（BossRushScorepad.tsv、BossRushSettings.tsv），重装 MOD 也不丢。

**下载**
N 网：https://www.nexusmods.com/phantombladezero/mods/1099

**安装**
1. 先装前置：KintaroxOe 的 OFFICIAL UE4SS for PBZ（N 网 https://www.nexusmods.com/phantombladezero/mods/13），装好后确认能正常运行。
2. 把压缩包解压到 `游戏目录\platform\steam\ue4ss\Mods\`，解压后应该是 `...\ue4ss\Mods\BossRush\Scripts\main.lua`。
3. 进游戏，敲响任意铃铛，就能看到「残影试炼」。

卸载：删掉 BossRush 文件夹即可，存档不受影响；要连最佳纪录和设置一起清掉，再删掉 `游戏目录\ProjectPBZ\Saved` 里的两个 BossRush*.tsv。

**兼容性**
只增加内容，不替换游戏文件、不改存档，可以和其他 UE4SS MOD、pak MOD 一起用。修改怪物数值或难度的 MOD，会连带改变挑战中首领的强度。

**目前的限制**
- 舞狮尊主只在它自己的战场「尊主封印地」打（跳桩那一段需要原场地），本周目敲响那里的铃铛后才能打。
- 金面具黑衣人和魔渊在「龙柱」铃铛敲响后在龙柱打，之前在其他场地。
- 梦差冷荼的技能离不开原关卡，暂未开放。
- 肉鸽玩法「万象」还没做完。
- 在 Steam 版上制作和测试。

## 0.1.6 更新（已发过帖子时：编辑原帖并把这段放在正文最前，或作为更新动态 / 评论发出）

**0.1.6 更新**（N 网已上线：https://www.nexusmods.com/phantombladezero/mods/1099 ）
- 新增「敌方 · 强度」：残影试炼新增「设置」页，其中「敌方 · 强度」一行按确认键在一重～五重之间切换。一重与之前相同；二重～五重在进度和周目提升之上，首领生命和杀气 ×1.5 / ×2.25 / ×3.4 / ×5，攻击和破气 ×1.4 / ×2 / ×2.7 / ×3.8，破势硬直更短。单挑、连战都用这一档，重启游戏后保留；最佳用时按档分开记（以前的纪录算一重），结算画面在难度后面显示档位。感谢 a1435033075 的建议。
- 首领出场：不再凭空出现、立刻出手。先在它要出现的位置浮现征兆，1.5 秒后首领在其中现身，原地停 1.5 秒再行动；出现距离从 8 米改为 12 米，场地窄时自动近一些。
- 新开放 8 位首领：灭法之法四人（炎茹、雷婷、蛊鹤、寒岁）、操偶师荡秽、组织冥主：左殇、龙体左殇、风雪刀客。共 74 位首领，只剩梦差冷荼暂未开放。
- 玉妖和铁鬼合为一行「少主护卫：玉妖铁鬼」，两人同时登场。
- 连战：千影归来拆成九段，按首领所在的地图分段，每段单独一局、单独计最佳用时（原来是全部首领一局打完）；它排在连战第一位，点进去是九段的列表。改名和调整顺序：温玉藏锋（原少主仪仗）、冥主麾下（原组织高手）、铁马残阳（原沙场宿将）、剑冢遗恨（原名门残影）；加回灭法之法。改名的组保留原有最佳用时。连战页进入时光标在「下一页」，和单挑一样。
- 每个连战组、每段千影都有自己的场地，敲响其铃铛后就去那里打。金面具黑衣人和舞狮尊主也能进连战了：整组去它们的专属战场打。
- 单挑有推荐场地的首领会去那里打（沐小葵：初见湖畔；风雪刀客：白影陨落之处）。
- 不再紧挨着铃铛开打：各场地离开铃铛重新标点，新增「白影陨落之处」「祠堂广场」，去掉「圣母雕像场」「高塔后方出口」，「湖畔」改名「初见湖畔」、「陆家村湖畔」改名「梅谷湖畔」。从铃铛出发时，画面淡出后把你移到场地上。
- 修复：悲痛欲绝的阿瑾打不死。
- 修复：在铃铛旁的场地战死后会原地复活、挑战继续；现在战死即以「饮恨」结束；镜花水月中战死被记成「收刃离去」的问题也一并修好。
- 修复（多周目）：专属战场「龙柱」「尊主封印地」只在本周目已敲响其铃铛时使用。之前在铃铛未敲的龙柱战死，可能导致游戏崩溃，存档也停在那个铃铛。铃铛未敲时，金面具黑衣人改在其他场地打；舞狮尊主会提示先敲响尊主封印地的铃铛。
- 感谢 mastersoul2 的反馈和测试，这两项修复都来自这位玩家的排查。
- 挑战中战死不再算游戏里的死亡：直接以「饮恨」结束，六十六天难度不折损天数，也不计入死亡次数。六十六天难度下进入残影试炼仍会提示尽量换用其他难度，以防意外身陨。
- 游戏更新后，mod 启动时会检查用到的游戏内容是否还在：缺少核心部件时残影试炼暂停并提示，待 mod 更新后恢复；缺少某位首领或某个场地时只去掉那一项。
